# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

Apache Superset 5.0 — an enterprise BI web application. Monorepo with a Python/Flask backend, React/TypeScript frontend, WebSocket sidecar, and embedded SDK.

## Common Commands

### Backend (Python)

```bash
# Install dependencies
pip install -r requirements/development.txt
pip install -e .

# Run dev server (port 8088, uses .flaskenv)
flask run -p 8088
# Or via Makefile:
make flask-app

# Database migrations
superset db upgrade
superset db revision -m "description"

# Run unit tests
pytest --cov=superset ./tests/common ./tests/unit_tests

# Run a single test file
pytest tests/unit_tests/path/to/test_file.py

# Run a single test
pytest tests/unit_tests/path/to/test_file.py::test_function_name

# Run integration tests (requires DB + Redis)
pytest --cov=superset ./tests/integration_tests

# Lint and format Python
ruff check superset/ tests/
ruff format superset/ tests/
mypy superset/
```

### Frontend (Node/npm, run from `superset-frontend/`)

```bash
npm ci                          # Install dependencies
npm run build                   # Production build (output: superset/static/assets/)
npm run dev-server              # Webpack dev server on port 9000
npm run dev                     # Watch mode build

# Tests
npm test                        # Run all Jest tests
npm run tdd                     # Watch mode
npm test -- --testPathPattern=<pattern>  # Run specific test file

# Lint and format
npm run lint                    # ESLint + TypeScript type check
npm run lint-fix                # ESLint with auto-fix
npm run prettier                # Prettier formatting
npm run type                    # tsc --noEmit (type checking only)
```

### Docker

```bash
docker compose up               # Full dev stack (app:8088, dev-server:9000, ws:8080)
```

## Architecture

### Backend Structure

- **App factory**: `superset/app.py` → `create_app()`, with `SupersetAppInitializer` in `superset/initialization/__init__.py` bootstrapping ~40 blueprints
- **Config**: `superset/config.py` holds all defaults, feature flags, and settings; override via `superset_config.py` or `SUPERSET_CONFIG_PATH` env var
- **Business logic**: Uses command pattern in `superset/commands/` — commands orchestrate validation + persistence, calling DAOs in `superset/daos/`
- **Models**: SQLAlchemy ORM in `superset/models/`
- **Views**: Flask-AppBuilder views in `superset/views/`; REST APIs in `superset/api/`
- **DB dialects**: `superset/db_engine_specs/` has one module per database engine (Postgres, MySQL, BigQuery, etc.)
- **Async tasks**: Celery workers defined in `superset/tasks/`; reports/alerts in `superset/reports/`
- **Migrations**: Alembic, in `superset/migrations/versions/`

### Frontend Structure

- **Entry**: `src/preamble.ts` → `src/views/App.tsx` (React Router v5 nested routes)
- **State**: Redux + React Context; root hydration from server-rendered HTML data attributes via `src/rootContext.ts`
- **Styling**: Emotion CSS-in-JS + Ant Design 4.x + Bootstrap 3
- **Key areas**:
  - `src/explore/` — chart exploration/visualization builder (complex)
  - `src/dashboard/` — dashboard rendering and layout
  - `src/views/CRUD/` — generic CRUD framework for datasets, charts, dashboards, queries
  - `src/filters/` — dashboard filter components
  - `src/features/` — feature-specific modules (alerts, annotations, home)
- **Packages**: `packages/` contains monorepo workspaces (`superset-ui-core`, `superset-ui-chart-controls`, `superset-ui-switchboard`)
- **Plugins**: `plugins/` has 18 chart visualization plugins, each independently buildable

### Frontend-Backend Integration

Backend renders a minimal HTML shell (Jinja2). `src/rootContext.ts` parses server-injected data attributes (user, CSRF token, feature flags). Axios client in `src/setup/setupClient.ts` handles API calls. All REST endpoints are in `superset/api/` or auto-generated by Flask-AppBuilder.

### Plugin System

Chart plugins register metadata, a React component, `buildQuery` function, `transformProps`, and `controlPanel` config via `@superset-ui/core` registries. Dynamic plugins load at runtime via `DynamicPluginProvider`.

## Code Style

- **Python**: Ruff for linting + formatting (Black-compatible, line-length 88, target Python 3.10). mypy for type checking in strict mode. Config in `pyproject.toml`.
- **TypeScript/JS**: ESLint (airbnb + prettier config) + Prettier (single quotes, trailing commas). Config in `superset-frontend/.eslintrc.js` and `prettier.config.js`.
- **Pre-commit hooks**: ruff, mypy, prettier, eslint — run `pre-commit install` to activate.
- **Indentation**: 4 spaces for Python, 2 spaces for JS/TS/CSS/HTML/JSON.
